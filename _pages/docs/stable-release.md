The current stable release is **SiteRM 1.6.3**.

> **Latest release:** `1.6.3` was promoted to the production release (`latest` tag) on **Thursday, September 10, 2026**, following validation of the `1.6.3-pre` pre-production build (published September 4, 2026). Sites should upgrade from `1.6.2`. See the [Release Notes](/docs/release-notes/) for the full 1.6.3 changelog and upgrade instructions.

> **Upcoming release:** `1.6.4-pre` was published Monday, September 21, 2026 as a pre-production release (`pre` tag). **1.6.3 remains the official production release** — `1.6.4-pre` is for validation only. Barring issues found during validation, `1.6.4-pre` is planned to be promoted to the production release (`latest` tag) around **Monday, September 28, 2026**. See the [Release Notes](/docs/release-notes/) for the full 1.6.4-pre changelog.

See the full [Release Notes](/docs/release-notes/) for details, upgrade instructions, and Docker/Helm version information.
