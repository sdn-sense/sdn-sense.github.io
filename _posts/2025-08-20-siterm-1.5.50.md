## What changed

- SiteRM migrates its REST API to FastAPI and exposes generated API documentation from each Frontend.
- Readiness and liveness endpoints provide application and process health signals.
- Configuration defaults move into the codebase, reducing the per-site configuration surface.
- Arista QoS handling distinguishes guaranteed-capped, soft-capped, and best-effort allocations while retaining minimum capacity for best-effort traffic.
- Agent images add Ubuntu 22 support.
- Model cleanup, database-failure handling, SSH reliability, certificate-expiry checks, and parallel Ansible cleanup are improved.

## Required upgrade review

This release changes the REST framework and database layout. Sites upgrading from 1.5.43 had to cancel active resources, update site configuration, and recreate the SiteRM database before starting the new image. Coordinate that procedure with the SENSE team rather than treating this as an in-place image-only upgrade.
