## Changes

- Daemonizer logs more detail while refreshing configuration.
- Alive and readiness checks stop polling once a service is fully ready.
- Published models include the SiteRM version.
- The Frontend removes service-state rows when a host is deleted, preventing false alarms.
- Port validation no longer accepts a nonexistent configured port when `allports` is enabled.

This release supports Frontend EL9, Agent EL8/EL9/EL10/Ubuntu 22, and Debugger EL10. EL10 is the default Agent image.
