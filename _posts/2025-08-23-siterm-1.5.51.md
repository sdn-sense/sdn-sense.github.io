## Fixes

- Ansible operations now time out instead of hanging during affected Edgecore cleanup paths.
- FastAPI documentation includes corrected defaults for Debugger actions.
- DebugService and ServiceStates calls use the corrected FastAPI behavior.
- The Frontend accepts `ethr-server` and `ethr-client` operations.

This release uses the same image and Helm chart matrix introduced with 1.5.50.
