## Changes

- SiteRM checks VLAN and IP overlap for every relevant request instead of only requests that include a new IP address.
- Port scanning now handles sites without a local switch, including nodes that connect to another domain through `isAlias`.

This release supports Frontend EL9, Agent EL8/EL9/EL10/Ubuntu 22, and Debugger EL10.
