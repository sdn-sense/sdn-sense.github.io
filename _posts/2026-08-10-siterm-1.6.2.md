## What changed

- Juniper MX and PTX routers can provision VLANs through a `virtual-switch` routing instance. Optional per-VLAN VSTP provides loop protection for those members.
- Agents can set `nodscp: true` to skip DSCP rules independently from the existing QoS toggle.
- Frontend, Agent, and Debugger can read local YAML configuration through `MAIN_CONFIG_FILE`, `AUTH_CONFIG_FILE`, `AUTH_RE_CONFIG_FILE`, and `MAPPING_TYPE` instead of a Git repository.
- Credentials can be restricted to configured IP ranges, and the Web UI exposes delta requester information.

## Reliability fixes

The release corrects certificate-chain verification, refresh-token control flow, stale switch-state detection, API readiness logic, delta tracking, SQLAlchemy connection URL handling, host statistics collection, and Juniper MX/PTX switchport detection.

Update the startup repository or Helm chart before changing image tags. See the [Juniper device guide]({{ '/devices/juniper-junos/' | relative_url }}) and [configuration layout]({{ '/customization/configuration-layout/' | relative_url }}) for the new options.
