## Changes

- Failed instance apply operations can be retried.
- OIDC configuration supports additional custom-provider settings.
- Provisioned instances no longer receive an incorrect recurring-time override when start and end times are omitted.
- L3 QoS application is corrected.
- Kubernetes and single-port instances without a switching service can be cancelled.
- HTTP calls use retries without overwriting Git configuration.
- Logging and warning/error reporting are clearer.

The release keeps the same supported operating-system matrix as 1.5.61.
