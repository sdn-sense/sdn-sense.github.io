## Fixes

- FRR VLAN extraction now recognizes dot-notation sub-interfaces such as `eth0.100`.
- Shared base64 helpers correctly accept both strings and bytes.
- Ansible backend failures persist switch error state so the Web UI and Prometheus output show the failure.
- Debugger operations use the correct request tables.
- Docker startup uses the corrected secret-mount directory name.

No manual database migration is required. Update the deployment repository or Helm chart, then move all SiteRM components to the 1.6.1 image or chart version together.
