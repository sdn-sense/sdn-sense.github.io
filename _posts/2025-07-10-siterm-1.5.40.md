## Frontend and model changes

- Delta and model APIs support Turtle, JSON-LD, and N-Triples. The backend moves to N-Triples for substantially faster model serialization.
- PolicyService and LookUpService wait for a complete first run before accepting deltas.
- Delta validation rejects overlapping IP requests.
- Prometheus exposes liveness and readiness state.
- Configurable traffic classes map to best-effort, soft-capped, and guaranteed-capped behavior.

## Agent, Debugger, and deployment changes

- Agent and Debugger run as separate containers, allowing the Debugger to run on any suitable host or public address for L3 actions.
- Debugger adds iPerf and FDT actions for L2 and L3 addresses.
- Junos operations roll back failed changes and validate switchport state.
- Containers no longer require privileged mode. Agent images cover EL8, EL9, and EL10, while Frontend moves to EL9 and Debugger to EL10.
- Helm charts move into the shared `sdn-sense/helm-charts` repository and add StatefulSet support plus more explicit networking, volume, and LLDP controls.

This was a staging release. SiteRM 1.5.41 promoted the validated feature set to production.
